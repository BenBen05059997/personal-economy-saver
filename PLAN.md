## Stages 20 to 24. A personal money agent with a canvas (D56 to D60)

Built in waves by Sonnet builders on the lead's contracts (D19); the lead reviews each wave and runs every check before the next starts. Layers call downward only: callers (screens, canvas, agent, MCP, daily job) → tools → engine → record. A block stores a query, never a number. One function per kind of change.

**Rules for every builder, every wave**
- Own only the files your box lists. Never edit `package.json` or its lock file, `eslint.config.mjs`, the docs (`DECISIONS.md`, `PLAN.md`, `AGENTS.md`, `ARCHITECTURE.md`, `BROWSER-CHECKS.md`, `economy-saver/README.md`), or another box's files. A package, an npm script or a lint change goes in the report; the lead adds it. No new package without the lead: mind the Worker's uncompressed size and startup time (S).
- One migration per wave, generated by the one box named for it with `npm run db:generate`; nobody else touches `src/db/schema.ts` or `drizzle/` in that wave. The owner applies migrations to Tokyo (`npm run db:migrate`), never a builder. Restart `next dev` after a schema change (AGENTS gotcha).
