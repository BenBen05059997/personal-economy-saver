# fipa: Personal Economy Saver

A personal money agent for people paid through PayPal. Home says, in one sentence with a date, whether you'll be short. One approved PayPal action (a sandbox payment link for finished work, or a request to a household member) changes that sentence once a verified webhook confirms the payment. Ask answers in your own words, reads bill photos and lays out charts. The AI only understands and words things: code does every sum, every check and every write, and nothing is sent or saved without your tap.

- **Live demo:** https://personal-economy-saver.globalperspectives-app.workers.dev. Press **Try it** for a fresh fictional household; no sign-up is needed.
- **Run it yourself:** see [economy-saver/README.md](economy-saver/README.md).
- **What it does and why:** see [DECISIONS.md](DECISIONS.md).
